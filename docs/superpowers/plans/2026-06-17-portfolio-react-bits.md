# Portfolio — React Bits + Content Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add React Bits animated components (Aurora, BlurText, RotatingText, ShinyText, CountUp, SpotlightCard) to the portfolio's Hero, section headers, and project cards, and update all content to match the current resume.

**Architecture:** React Bits components are installed via CLI into `src/components/ui/`. Each is then imported into the specific section/component files that need them. Content updates happen exclusively in `src/data/data.ts`. No structural changes to pages, routing, or CSS variables.

**Tech Stack:** React 19, TypeScript 5.9, Vite 7, Lucide React, React Bits (via `npx reactbits@latest add`)

## Global Constraints

- Keep existing color variables: `--primary: #6366f1`, `--secondary: #8b5cf6`, `--accent: #ec4899`, `--bg-dark: #0f172a`
- Install every React Bits component via `npx reactbits@latest add <name>` — read the generated file before using it to confirm prop names
- No new routes, no new pages, no restructuring beyond what each task requires
- All code must type-check (`npm run build` exits 0)
- After each visual task: check mobile at 768px before committing


Read the generated file to confirm prop names (typically: `className`, `spotlightColor`, `children`).

- [ ] **Step 2: Replace the contents of `src/components/ProjectCard.tsx`**

```tsx
import { Github, ExternalLink, Star } from 'lucide-react';
import type { Project } from '../types';
import SpotlightCard from './ui/SpotlightCard';

interface ProjectCardProps {
  project: Project;
  index: number;
}

const ProjectCard = ({ project, index }: ProjectCardProps) => {
  return (
    <SpotlightCard
      className="project-card"
      spotlightColor="rgba(99, 102, 241, 0.15)"
      style={{ animationDelay: `${index * 0.1}s` }}
    >
      <div className="project-header">
        <h3>{project.name}</h3>
        {project.stars && (
          <div className="project-stars">
            <Star size={16} fill="currentColor" />
            <span>{project.stars}</span>
          </div>
        )}
      </div>
      <p className="project-description">{project.description}</p>
      <div className="project-tech">
        {project.tech.map((tech, i) => (
          <span key={i} className="tech-tag">{tech}</span>
        ))}
      </div>
      <a
        href={project.github}
        target="_blank"
        rel="noopener noreferrer"
        className="project-link"
      >
        <Github size={18} />
        <span>Ver no GitHub</span>
        <ExternalLink size={14} />
      </a>
    </SpotlightCard>
  );
};

export default ProjectCard;
```

> If SpotlightCard doesn't accept a `style` prop, wrap the whole component in a div with the animation delay:
> ```tsx
> <div style={{ animationDelay: `${index * 0.1}s` }}>
>   <SpotlightCard className="project-card" spotlightColor="rgba(99, 102, 241, 0.15)">
>     ...
>   </SpotlightCard>
> </div>
> ```
